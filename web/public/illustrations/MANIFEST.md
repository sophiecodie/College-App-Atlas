# CollegeAtlas illustration manifest

All files here are generated by `node scripts/generate-illustrations.mjs` from one palette and one set of
drawing helpers (flat storybook style). They're placeholders for painted or pixel-art versions matching the
design references. Text, buttons and progress indicators are never part of the artwork.

To replace a piece: add the new file (PNG/WebP/SVG, transparent background where noted), then update its
path and size in `src/lib/illustrations.ts`. Keep the same aspect ratio so layouts don't shift.
